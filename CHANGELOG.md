# Changelog — Vevfrontgame fork

This document records modifications made in this fork relative to the
upstream OpenFrontIO project, as required by AGPL v3.0 Section 5(a).

## Fork base

- Upstream project: https://github.com/openfrontio/OpenFrontIO
- Tag: `v0.26.6`
- Commit: `f552b006613c2dee52209801fe2875c64923fcc8`
- Date of upstream commit: 15 October 2025

## Modifications

The following changes have been applied in this fork:

### Files removed

- `/proprietary/` directory
- `/static/` directory (build output; regenerated by `npm run build`)
- Background music tracks; the audio class continues to function and accepts user-supplied tracks placed in `resources/sounds/music/`

### Content changes in `src/client/index.html`

- Replaced the upstream landing page content with a neutral title and description for this fork
- Replaced the upstream footer with a footer referencing this fork's source repository and licenses
- Removed external links and integrations that pointed to third-party services and platforms operated by upstream maintainers
- Removed third-party analytics and tracking scripts
- Removed promotional and storefront widgets

### Content changes in `src/client/`

- Updated copyright notices to reference this fork
- Adjusted `WinModal.ts` to remove end-of-game promotional content
- Updated `SoundManager.ts` to remove references to the removed audio files

### Configuration changes

- Updated `src/server/OtelResource.ts`, `src/server/Logger.ts`, `src/server/WorkerMetrics.ts`: renamed service identifiers
- Updated `src/core/configuration/ProdConfig.ts` and `src/core/configuration/PreprodConfig.ts`: renamed JWT audience values
- Removed deployment-specific configuration files and scripts

### Documentation

- Rewrote `README.md`, `LICENSING.md`
- Added `NOTICE.md` (attribution and disclaimer)
- Added this `CHANGELOG.md`

### Assets

- Removed branded image files from `src/client/` and `resources/images/`
- Removed branded icons from `resources/icons/`
- Cleared the cosmetics catalog at `resources/cosmetics/cosmetics.json`
